Вопрос 1: Что такое Git и для чего он используется?
Git — это распределённая система контроля версий, которая отслеживает все изменения в файлах проекта. Вместо того чтобы хранить только последнюю версию, Git сохраняет полную историю всех изменений. Это позволяет: 
Вернуться к любой предыдущей версии проекта
Видеть, кто и когда изменил каждую строку кода
Объединять работу нескольких программистов без конфликтов
Создавать отдельные ветки для экспериментов, не трогая основной код
Git используется в профессиональной разработке, потому что он помогает командам эффективнее работать вместе и минимизирует риск потери данных. 

Вопрос 2: В чём разница между централизованными и распределёнными системами контроля версий?
Централизованные системы (SVN, Perforce): Один центральный сервер хранит всю историю проекта. Каждый разработчик скачивает только последнюю версию и отправляет свои изменения на сервер. Если сервер упадёт, никто не может работать. 

Распределённые системы (Git, Mercurial): Каждый разработчик имеет полную копию истории проекта на своём компьютере. Это означает, что: 
Каждый может работать офлайн
Если один сервер упадёт, данные сохранены у всех участников
Работа локальнее и быстрее
Распределённый подход более надёжен и гибкий, поэтому Git стал стандартом индустрии. 

Вопрос 3: Что такое репозиторий в Git?
Репозиторий (англ. repository) — это специальная папка в проекте, которая содержит всю историю изменений файлов. Внутри скрытой папки .git хранятся: 
Все коммиты (снимки состояния проекта)
Ветки (параллельные линии развития)
Информация об авторе каждого изменения
Теги (метки для версий)
Репозиторий может быть локальным (на вашем компьютере) или размещаться на сервере (например, GitHub). Локальный репозиторий позволяет работать независимо, а сервер — делиться кодом с товарищами.
