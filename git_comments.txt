git clone - копирует удалённый репозиторий на компьютер;
git status - показывает состояние файлов;
git add - добавляет изменения в индекс;
git commit - создаёт коммит с изменениями;
git push - отправляет изменения на GitHub;
git pull - загружает изменения с GitHub;
git log - показывает историю коммитов;
git branch - управляет ветками;
git checkout - переключает ветки;
git merge - объединяет ветки;
git diff - показывает различия;
git init - создаёт новый репозиторий.
